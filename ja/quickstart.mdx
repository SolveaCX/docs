Flatkey は1つのキーと、それを使う4つの方法を提供します。この4つはすべて同じアカウント、同じ残高、同じモデルカタログを共有しています——つまり問題は、どれがあなたの作業スタイルに合うかだけです。

<Frame>
  ![Flatkey Console に表示された、Flatkey を使う4つの方法](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  一度きりの選択にする必要はありません。今取り組んでいることに最も近いものから始めて、同じキーに対して後から他の方法を追加してください。
</Tip>

## 始める前に

[console.flatkey.ai/keys](https://console.flatkey.ai/keys) でキーを作成してください。Flatkey のキーは `sk-` で始まります。以下のすべての選択肢はこの1つのキーを使うので、環境変数に保存し、ソースコード管理には含めないようにしてください。

Console の各パネルでは、新しいキーを作成する代わりに既存のキーを選ぶこともでき、表示されるスニペットにそのまま挿入されます。

## 開発者向け API

OpenAI 互換のリクエストで、どのモデルもプレーンな HTTP 経由で呼び出せます。SDK も依存関係も不要です——HTTP クライアントさえあれば準備完了です。

<Frame>
  ![すぐに実行できるリクエストを備えた、開発者向け API パネル](/images/quickstart/modal-api.png)
</Frame>

Console がリクエストを構築してくれます。キーとモデルを選び、**cURL**、**Node.js**、**Python** のいずれかでスニペットをコピーするだけです。

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## 開発者向け SDK

すでに使っている OpenAI SDK をそのまま使い、Flatkey に向けるだけです。リクエストのコードは変わりません——変わるのはベース URL だけです。

<Frame>
  ![SDK セットアップを示す、開発者向け SDK パネル](/images/quickstart/modal-sdk.png)
</Frame>

上記と同じ考え方です。キーとモデルを選び、お使いの言語向けのセットアップをコピーしてください。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## Flatkey CLI

ターミナルから画像や動画を生成する、あるいは AI アシスタントに CLI を操作させます。

<Frame>
  ![インストール、サインイン、最初のプロンプトを示す、Flatkey CLI パネル](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="インストール">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="サインイン">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="作成を始める">
    AI アシスタントに欲しいものを伝えて、CLI を実行させましょう:

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

## Codex & Claude Code

コーディングエージェントを一度接続すれば、すでに開いているプロジェクトから Flatkey を利用できます。

<Frame>
  ![インストールコマンドを示す、Codex と Claude Code のパネル](/images/quickstart/modal-agents.png)
</Frame>

Console は **macOS**、**Linux**、**Windows** 向けに単一のインストールコマンドを提供します。エージェントが未インストールならインストールし、キーの入力を求め、設定を書き込んでくれます。

<Warning>
  インストーラーは対話形式です。Claude Code か Codex CLI かを尋ねられ、事前に Node.js がインストールされている必要があります。
</Warning>

## 動作確認をする

どの方法を選んでも、最初のリクエストの後に [Console](https://console.flatkey.ai) の **Usage Logs** を開いてください。モデル、トークン数、レイテンシー、コストとともにリクエストが記録されているはずです。

![Flatkey Usage Logs でモデル名フィルターを使う](/images/quickstart/flatkey-usage-logs.png)

何も表示されない場合は、数秒待ってから再度検索し、リクエストが実際に使用した API キーとベース URL を確認してください。

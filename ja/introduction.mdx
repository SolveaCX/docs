## 対応プロバイダー

Flatkeyは主要なAIベンダー全社の公式APIにルーティングします。

| プロバイダー | モデル例 |
|---|---|
| OpenAI | gpt-4o, gpt-4o-mini, gpt-5, gpt-image-2 |
| Anthropic | claude-opus-4, claude-sonnet-4, claude-haiku-4 |
| Google | gemini-2.5-pro, gemini-2.5-flash, gemini-flash-latest |
| DeepSeek | deepseek-v3, deepseek-v4-pro, deepseek-v4-flash |
| Qwen | qwen3.5-plus, qwen3.7-max, qwen3.5-flash |
| Z.ai / GLM | glm-4.7, glm-5-turbo, glm-5.2 |
| ByteDance | seedance-2.0, seedance-2.5 |

300以上の全モデルのライブ価格とヘルスデータは[モデルディレクトリ](https://flatkey.ai/models)をご覧ください。

## 仕組み

FlatkeyはアプリケーションとAIプロバイダーの間に位置します。リクエストを送信すると：

1. クライアントがFlatkey APIキーを使って`https://router.flatkey.ai/v1`を呼び出します。
2. Flatkeyがリクエストを認証し、プリペイド残高からコストを差し引きます。
3. リクエストが公式プロバイダーAPI（OpenAI、Anthropicなど）に転送されます。
4. レスポンスがコンテンツを変換することなく直接クライアントに返されます。

データの取り扱い要件については、Flatkeyと選択したプロバイダーの現行のプライバシー規約をご確認ください。保持期間の確認やセキュリティ評価については、[support@flatkey.ai](mailto:support@flatkey.ai) にお問い合わせください。

<Note>
  大量利用をご検討ですか？[お問い合わせページ](https://flatkey.ai/contact)を開き、**エンタープライズ**プランを見つけて、**営業に問い合わせる**を選択してください。エンタープライズ契約には、コミット量割引、カスタムルーティング、請求書発行、および調達サポートが含まれます。
</Note>

セルフサービスプランは、個人および小規模チームのほとんどのワークロードに対応しています。利用量、支払いプロセス、または調達要件がセルフサービスプランの範囲を超えた場合に、エンタープライズ契約が適しています。

## 契約と請求

<Accordion title="エンタープライズ契約への移行を検討すべき時期は？">
  セルフサービスプランで利用量が上限に達した場合、チームがカード払いではなく請求書払いを必要とする場合、または調達に署名済み契約が必要な場合は、エンタープライズ契約をご検討ください。ご不明な点がある場合は、月間トークン量と対象モデルを [support@flatkey.ai](mailto:support@flatkey.ai) までお知らせください。
</Accordion>

<Accordion title="エンタープライズ契約に含まれるものは何ですか？">
  エンタープライズ料金はカスタムです。契約には、コミット量割引、カスタムルーティング、請求書発行、および調達サポートが含まれます。具体的な条件は利用量とモデルの組み合わせによって異なります。詳細は[料金ページ](https://flatkey.ai/pricing)の**エンタープライズ**プランをご覧ください。
</Accordion>

<Accordion title="Flatkey は請求書ベースの請求に対応していますか？">
  はい。エンタープライズアカウントは、請求書払い、カスタム月次利用、チーム調達、および専用ルーティング割引に対応しています。条件については [support@flatkey.ai](mailto:support@flatkey.ai) までお問い合わせください。
</Accordion>

## チームとアクセス制御

<Accordion title="複数人で 1 つのエンタープライズアカウントを共有できますか？">
  はい。担当者またはサービスごとに個別の API キーを発行し、**グループ**を使用してモデルアクセスポリシーとスペンドクォータを各キーに適用します。すべてのリクエストはキーとともに**使用ログ**に記録されるため、チームやプロジェクトごとにコストを把握できます。
</Accordion>

<Accordion title="キーがアクセスできるモデルを制限できますか？">
  はい。コンソールの**グループ**を使用して、個別キーまたはキーグループに対してモデルアクセスポリシーとスペンドクォータを設定できます。
</Accordion>

## セキュリティレビュー

<Accordion title="ベンダーセキュリティレビューに必要なものは何ですか？">
  アンケートを [support@flatkey.ai](mailto:support@flatkey.ai) までお送りください。Flatkey のデータ保持とコンプライアンスの姿勢については、FAQ の[プライバシーとセキュリティ](/ja/reference/faq#プライバシーとセキュリティ)にまとめられています。
</Accordion>

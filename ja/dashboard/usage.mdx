Flatkey の **使用状況**ダッシュボードでは、アカウントで行われたすべてのAPIリクエストを完全に把握できます。各ログエントリには、使用されたモデル、入力および出力トークン数、残高から差し引かれたコスト、タイムスタンプが表示されます。このビューを使用して、支出パターンの把握、エラーのデバッグ、コストの照合を行えます。

## 使用状況ログへのアクセス

<Steps>
  <Step title="コンソールを開く">
    [console.flatkey.ai](https://console.flatkey.ai) にログインし、左サイドバーの**使用状況**をクリックします。
  </Step>
  <Step title="日付範囲を設定する">
    上部の日付ピッカーを使用して、日、週、月、またはカスタム範囲でログをフィルタリングします。デフォルトビューでは過去7日間が表示されます。
  </Step>
  <Step title="モデルまたはキーでフィルタリングする">
    **モデル**および**APIキー**のドロップダウンを使用して、特定のモデルまたはキーに絞り込みます。これはモデル間のコスト比較や特定のインテグレーションの監査に役立ちます。
  </Step>
</Steps>

## 各ログエントリの表示内容

| フィールド | 説明 |
|---|---|
| **タイムスタンプ** | Flatkey がリクエストを受信した日時 |
| **モデル** | 使用されたモデルID（例：`gpt-4o-mini`、`claude-sonnet-4-5`） |
| **入力トークン** | プロンプト内のトークン数 |
| **出力トークン** | 補完内のトークン数 |
| **コスト** | このリクエストで残高から差し引かれた金額 |
| **APIキー** | 使用されたキー（名前＋マスクされたプレフィックスで表示） |
| **ステータス** | リクエストが成功したか失敗したか |

## コストの仕組み

各リクエストには実際に請求されたコストが表示されます。これには以下が反映されています：
- モデルの入力および出力価格（Flatkey の割引レート適用後）
- 自動的に適用される現在のトップアップボーナス

すべてのリクエストコストの合計が、その期間に消費された残高の合計と一致します。

## 残高の監視

現在の残高は使用状況ページの上部および**残高**セクションに表示されます。設定した閾値を下回ると、メールアラートが届きます。アラートを設定するには、**設定 → 通知**に移動してください。

<Note>
  残高はリクエストが完了するたびにリアルタイムで差し引かれます。プロバイダー側でリクエストが失敗した場合でも、失敗前に処理されたトークン数に応じてコストが一部差し引かれる場合があります。
</Note>

## ログのエクスポート

使用状況データをエクスポートするには：
1. 希望の日付範囲とフィルターを設定します。
2. 右上の**エクスポート**をクリックします。
3. CSVまたはJSON形式を選択します。
4. ファイルがブラウザにダウンロードされます。

エクスポートされたログにはダッシュボードに表示されるすべてのフィールドが含まれており、スプレッドシートや財務ツールへのアップロードに適しています。

## 高使用量アラート

予期しない高額支出を防ぐには：
- **設定 → 請求**で**月次支出上限**を設定します — 上限に達するとリクエストがブロックされます。
- **グループ**を使用して、キーごとまたはアプリケーションごとのクォータを設定します。

<Tip>
  開発中は、少額（例：$5）の支出クォータを設定した別のキーを使用してください。これにより、誤って高コストなリクエストが発生しても本番環境の残高が枯渇するのを防げます。
</Tip>

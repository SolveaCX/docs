|---|---|
| OpenAI | gpt-4o, gpt-4o-mini, gpt-5, gpt-image-2 |

| Google | gemini-2.5-pro, gemini-2.5-flash, gemini-flash-latest |
| DeepSeek | deepseek-v3, deepseek-v4-pro, deepseek-v4-flash |
| Qwen | qwen3.5-plus, qwen3.7-max, qwen3.5-flash |

Consulta el [Directorio de modelos](https://flatkey.ai/models) completo para ver los más de 300 modelos con precios en tiempo real y datos de salud.

## Cómo funciona

Flatkey se sitúa entre tu aplicación y los proveedores de IA. Cuando envías una solicitud:

1. Tu cliente llama a `https://router.flatkey.ai/v1` con tu clave de API de Flatkey.
2. Flatkey autentica la solicitud y deduce el coste de tu saldo de prepago.
3. La solicitud se reenvía a la API oficial del proveedor (OpenAI, Anthropic, etc.).
4. La respuesta se devuelve directamente a tu cliente, sin transformar el contenido.

Consulta las condiciones de privacidad vigentes de Flatkey y del proveedor elegido para conocer los requisitos de tratamiento de datos. Contacta con [support@flatkey.ai](mailto:support@flatkey.ai) para confirmar los plazos de conservación o solicitar una evaluación de seguridad.

Flatkey es una pasarela de API de IA que te permite acceder a más de 300 modelos oficiales de OpenAI, Anthropic, Google, DeepSeek, Qwen, GLM y otros, además de más de 1000 herramientas, todo a través de una única clave de API compatible con OpenAI. Es un reemplazo directo para cualquier cliente compatible con OpenAI: cambia una línea de código (`base_url`) y tus solicitudes se enrutan a través de Flatkey con hasta un 50% de descuento sobre el precio oficial.

## Cómo funciona

Flatkey se sitúa entre tu aplicación y los proveedores de IA. Cuando envías una solicitud:

1. Tu cliente llama a `https://router.flatkey.ai/v1` con tu clave de API de Flatkey.
2. Flatkey autentica la solicitud y deduce el coste de tu saldo de prepago.
3. La solicitud se reenvía a la API oficial del proveedor (OpenAI, Anthropic, etc.).
4. La respuesta se devuelve directamente a tu cliente, sin transformar el contenido.

Tus prompts y respuestas nunca se almacenan. Flatkey solo registra metadatos (modelo, conteo de tokens, marcas de tiempo) para facturación y análisis.

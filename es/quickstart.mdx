Realiza tu primera solicitud a Flatkey en unos cinco minutos. Solo necesitas una clave API y la URL base compatible con OpenAI `https://router.flatkey.ai/v1`.

<Tip>
  ¿Ya usas el SDK de OpenAI? Mantén el código de tu solicitud y cambia la URL base a `https://router.flatkey.ai/v1`.
</Tip>

## Antes de empezar

Necesitas:

- Una [cuenta de Flatkey](https://console.flatkey.ai/sign-up)
- cURL, Python 3.10+, Node.js 22+ o PowerShell
- Crédito prepago para la solicitud al modelo

<Steps>
  <Step title="Configura tu cuenta y clave API">
    Inicia sesión en la [consola de Flatkey](https://console.flatkey.ai). Abre **Wallet** y elige un paquete prepago que se ajuste a tu carga de trabajo.

    ![Elige un paquete prepago en el Wallet de Flatkey](/images/quickstart/flatkey-top-up.png)

    A continuación, abre **API Keys** y selecciona **Create API Key**.

    ![Abre API Keys y selecciona Create API Key](/images/quickstart/flatkey-api-keys.png)

    Asigna un nombre claro a la clave. También puedes establecer un límite de crédito y un tiempo de expiración antes de seleccionar **Save changes**.

    ![Configura el nombre, el límite de crédito y la expiración de una clave API de Flatkey](/images/quickstart/flatkey-create-api-key.png)

    Copia el secreto generado y guárdalo en un lugar seguro. Las claves API de Flatkey comienzan con `sk-fk-`.

    <Warning>
      Nunca confirmes una clave API en el control de versiones ni la expongas en código del lado del navegador. Usa una variable de entorno o un gestor de secretos.
    </Warning>
  </Step>

  <Step title="Envía tu primera solicitud">
    Establece la clave API en tu shell actual:

    <CodeGroup>
    ```bash macOS and Linux
    export FLATKEY_API_KEY="sk-fk-..."
    ```
    ```powershell Windows PowerShell
    $env:FLATKEY_API_KEY="sk-fk-..."
    ```
    </CodeGroup>

    Para Python, instala el SDK de OpenAI con `pip install openai`. Para TypeScript, ejecuta `npm install openai`. cURL y PowerShell no necesitan ningún SDK.

    Los siguientes ejemplos llaman al mismo modelo a través del mismo endpoint de Flatkey:

    <CodeGroup>
    ```bash cURL
    curl https://router.flatkey.ai/v1/chat/completions \
      -H "Authorization: Bearer $FLATKEY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-4o-mini",
        "messages": [
          {"role": "user", "content": "Hello! What can you do?"}
        ]
      }'
    ```
    ```python Python
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ["FLATKEY_API_KEY"],
        base_url="https://router.flatkey.ai/v1",
    )

    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "user", "content": "Hello! What can you do?"}
        ],
    )

    print(response.choices[0].message.content)
    ```
    ```typescript TypeScript
    import OpenAI from "openai";

    const client = new OpenAI({
      apiKey: process.env.FLATKEY_API_KEY,
      baseURL: "https://router.flatkey.ai/v1",
    });

    const response = await client.chat.completions.create({
      model: "gpt-4o-mini",
      messages: [
        { role: "user", content: "Hello! What can you do?" },
      ],
    });

    console.log(response.choices[0].message.content);
    ```
    ```powershell PowerShell
    $headers = @{
      Authorization = "Bearer $env:FLATKEY_API_KEY"
      "Content-Type" = "application/json"
    }

    $body = @{
      model = "gpt-4o-mini"
      messages = @(
        @{ role = "user"; content = "Hello! What can you do?" }
      )
    } | ConvertTo-Json -Depth 4

    $response = Invoke-RestMethod `
      -Uri "https://router.flatkey.ai/v1/chat/completions" `
      -Method Post `
      -Headers $headers `
      -Body $body

    $response.choices[0].message.content
    ```
    </CodeGroup>

    Una vez completada la solicitud, abre **Usage Logs** en la consola de Flatkey. Introduce `gpt-4o-mini` en **Model Name** y selecciona **Search**. La captura de pantalla muestra dónde aplicar el filtro; tu solicitud completada debería aparecer en la tabla con el recuento de tokens, la latencia y el coste.

    ![Usa el filtro Model Name en los registros de uso de Flatkey](/images/quickstart/flatkey-usage-logs.png)

    Si la tabla sigue mostrando **No Logs Found**, espera unos segundos y vuelve a buscar. Si continúa vacía, comprueba la clave API y la URL base utilizadas en la solicitud.
  </Step>

## Lee la respuesta

En las respuestas de Chat Completions, los campos que usarás con más frecuencia son:

- `choices[0].message.content` — texto generado
- `model` — el modelo que procesó la solicitud
- `usage` — recuentos de tokens de prompt, completado y total

Consulta la [referencia de Chat Completions](/es/api-reference/chat-completions) para ver el esquema completo.

## Transmite la respuesta

Establece `stream` en `true` cuando quieras recibir los tokens a medida que se generan.

Los ejemplos de Python y TypeScript reutilizan el `client` que creaste en **Envía tu primera solicitud**.

<CodeGroup>
```bash cURL
curl --no-buffer https://router.flatkey.ai/v1/chat/completions \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "Write a two-line welcome message."}
    ],
    "stream": true
  }'
```
```python Python
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "Write a two-line welcome message."}
    ],
    stream=True,
)

for chunk in stream:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```
```typescript TypeScript
const stream = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [
    { role: "user", content: "Write a two-line welcome message." },
  ],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```
</CodeGroup>

## Gestiona los errores comunes

| Estado HTTP | Lo que suele significar | Qué hacer |
|---|---|---|
| `401` | La clave API falta, no es válida o ha sido revocada | Comprueba la cabecera `Authorization: Bearer` y crea una nueva clave si es necesario |
| `401 insufficient_balance` | El saldo prepago está agotado | Añade crédito desde **Wallet** |
| `503 model_not_found` | El ID del modelo está mal escrito o no está disponible | Comprueba el [Directorio de modelos](https://flatkey.ai/models) para obtener el ID exacto. Reintentar no ayuda |
| `429` | La solicitud superó un límite de velocidad | Reintenta con retroceso exponencial y jitter |
| `500` o `503` | El proveedor o la ruta no está disponible temporalmente | Lee primero `error.code` en el cuerpo de la respuesta. Reintenta con retroceso y consulta el [estado de los modelos](https://flatkey.ai/status) |

<Note>
  Un `503` puede significar tanto una interrupción temporal como un ID de modelo desconocido. Lee `error.code` en el cuerpo de la respuesta antes de reintentar.
</Note>

Consulta [Errores de API](/es/api-reference/errors) para ver los formatos de respuesta y los detalles de resolución de problemas.

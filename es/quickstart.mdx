Flatkey te ofrece una clave y cuatro formas de usarla. Las cuatro comparten la misma cuenta, el mismo saldo y el mismo catálogo de modelos, así que la única pregunta es cuál se adapta mejor a tu forma de trabajar.

<Frame>
  ![Las cuatro formas de usar Flatkey, mostradas en la Consola de Flatkey](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  No tienes que elegir de forma definitiva. Empieza con la opción más cercana a lo que estás haciendo hoy y añade las demás más adelante usando la misma clave.
</Tip>

## Antes de empezar

Crea una clave en [console.flatkey.ai/keys](https://console.flatkey.ai/keys). Las claves de Flatkey empiezan por `sk-`. Todas las opciones siguientes usan esa misma clave, así que guárdala en una variable de entorno y fuera del control de versiones.

Cada panel de la Consola también te permite elegir una clave existente en lugar de crear una nueva, e insertarla directamente en el fragmento de código que te muestra.

## API para desarrolladores

Llama a cualquier modelo mediante HTTP plano con una solicitud compatible con OpenAI. Sin SDK, sin dependencias: si tienes un cliente HTTP, ya estás listo.

<Frame>
  ![El panel de API para desarrolladores, con una solicitud lista para ejecutar](/images/quickstart/modal-api.png)
</Frame>

La Consola construye la solicitud por ti: elige una clave, elige un modelo y copia el fragmento en **cURL**, **Node.js** o **Python**.

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## SDKs para desarrolladores

Conserva el SDK de OpenAI que ya usas y apúntalo a Flatkey. El código de tu solicitud no cambia, solo cambia la URL base.

<Frame>
  ![El panel de SDKs para desarrolladores, con la configuración del SDK](/images/quickstart/modal-sdk.png)
</Frame>

La misma idea que antes: elige una clave y un modelo, y luego copia la configuración para tu lenguaje.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## CLI de Flatkey

Genera imágenes y vídeo desde tu terminal, o deja que un asistente de IA maneje la CLI por ti.

<Frame>
  ![El panel de la CLI de Flatkey, mostrando instalación, inicio de sesión y primer prompt](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="Instalar">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="Iniciar sesión">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="Empezar a crear">
    Pide a tu asistente de IA lo que quieres, y deja que ejecute la CLI:

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

<Card title="CLI de Flatkey con agente de IA" icon="terminal" href="/es/guides/flatkey-cli">
  Comandos, salida en JSON para agentes y recuperación de errores.
</Card>

## Codex y Claude Code

Conecta tu agente de codificación una vez y luego usa Flatkey desde los proyectos que ya tienes abiertos.

<Frame>
  ![El panel de Codex y Claude Code, con el comando de instalación](/images/quickstart/modal-agents.png)
</Frame>

La Consola te ofrece un único comando de instalación para **macOS**, **Linux** o **Windows**. Instala el agente si no lo tienes, te pide tu clave y escribe la configuración por ti.

<Warning>
  El instalador es interactivo. Pregunta si quieres Claude Code o Codex CLI, y necesita tener Node.js ya instalado.
</Warning>

## Comprueba que ha funcionado

Sea cual sea la opción que hayas elegido, abre **Usage Logs** en la [Consola](https://console.flatkey.ai) después de tu primera solicitud. Deberías verla listada con el modelo, el recuento de tokens, la latencia y el coste.

![Usa el filtro Model Name en los registros de uso de Flatkey](/images/quickstart/flatkey-usage-logs.png)

Si no aparece nada, espera unos segundos y busca de nuevo, y luego confirma la clave de API y la URL base que se usaron realmente en la solicitud.

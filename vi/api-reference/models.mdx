Endpoint `/v1/models` trả về danh sách tất cả các mô hình có sẵn qua tài khoản Flatkey của bạn. Phản hồi tuân theo định dạng OpenAI API — các ID mô hình được trả về ở đây có thể được sử dụng trong `/v1/chat/completions`, `/v1/embeddings` và các endpoint khác.

## Endpoint

```
GET https://router.flatkey.ai/v1/models
```

## Yêu cầu

### Headers

| Header | Giá trị |
|---|---|
| `Authorization` | `Bearer $FLATKEY_API_KEY` |

Không cần request body.

## Ví dụ yêu cầu

<CodeGroup>
```python python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)

models = client.models.list()

for model in models.data:
    print(model.id)
```
```javascript node
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.FLATKEY_API_KEY,
  baseURL: "https://router.flatkey.ai/v1",
});

const models = await client.models.list();

for (const model of models.data) {
  console.log(model.id);
}
```
```bash curl
curl https://router.flatkey.ai/v1/models \
  -H "Authorization: Bearer $FLATKEY_API_KEY"
```
</CodeGroup>

### Các trường phản hồi

<ResponseField name="data" type="array">
  Mảng các đối tượng model.
  <Expandable title="đối tượng model">
    <ResponseField name="id" type="string">Định danh mô hình để sử dụng trong các yêu cầu.</ResponseField>
    <ResponseField name="object" type="string">Luôn là `"model"`.</ResponseField>

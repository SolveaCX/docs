Flatkey adalah gateway API AI yang memungkinkan Anda mengakses 300+ model resmi dari OpenAI, Anthropic, Google, DeepSeek, Qwen, GLM, dan lainnya, ditambah 1000+ alat — semua melalui satu kunci API yang kompatibel dengan OpenAI. Ini adalah pengganti langsung untuk klien apa pun yang kompatibel dengan OpenAI: ubah satu baris kode (`base_url`) dan permintaan Anda akan diarahkan melalui Flatkey dengan harga hemat hingga 50% dari harga resmi.

## Cara kerjanya

Flatkey berada di antara aplikasi Anda dan penyedia AI. Ketika Anda mengirim permintaan:

1. Klien Anda memanggil `https://router.flatkey.ai/v1` dengan kunci API Flatkey Anda.
2. Flatkey mengautentikasi permintaan dan mengurangi biaya dari saldo prabayar Anda.
3. Permintaan diteruskan ke API penyedia resmi (OpenAI, Anthropic, dll.).
4. Respons dikembalikan langsung ke klien Anda — tanpa transformasi konten.

Prompt dan hasil Anda tidak pernah disimpan. Flatkey hanya mencatat metadata (model, jumlah token, stempel waktu) untuk penagihan dan analitik.

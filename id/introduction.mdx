## Penyedia yang didukung

Flatkey mengarahkan ke API resmi dari semua vendor AI utama:

| Penyedia | Contoh model |
|---|---|
| OpenAI | gpt-4o, gpt-4o-mini, gpt-5, gpt-image-2 |
| Anthropic | claude-opus-4, claude-sonnet-4, claude-haiku-4 |
| Google | gemini-2.5-pro, gemini-2.5-flash, gemini-flash-latest |
| DeepSeek | deepseek-v3, deepseek-v4-pro, deepseek-v4-flash |
| Qwen | qwen3.5-plus, qwen3.7-max, qwen3.5-flash |
| Z.ai / GLM | glm-4.7, glm-5-turbo, glm-5.2 |
| ByteDance | seedance-2.0, seedance-2.5 |

Lihat [Direktori Model](https://flatkey.ai/models) lengkap untuk semua 300+ model dengan harga dan data kesehatan secara langsung.

## Cara kerjanya

Flatkey berada di antara aplikasi Anda dan penyedia AI. Ketika Anda mengirim permintaan:

1. Klien Anda memanggil `https://router.flatkey.ai/v1` dengan kunci API Flatkey Anda.
2. Flatkey mengautentikasi permintaan dan mengurangi biaya dari saldo prabayar Anda.
3. Permintaan diteruskan ke API penyedia resmi (OpenAI, Anthropic, dll.).
4. Respons dikembalikan langsung ke klien Anda — tanpa transformasi konten.

Tinjau ketentuan privasi terkini Flatkey dan penyedia pilihan Anda untuk persyaratan penanganan data. Hubungi [support@flatkey.ai](mailto:support@flatkey.ai) untuk mengonfirmasi jangka waktu penyimpanan atau membahas penilaian keamanan.

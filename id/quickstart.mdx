Flatkey memberi Anda satu kunci dan empat cara untuk menggunakannya. Keempatnya berbagi akun yang sama, saldo yang sama, dan katalog model yang sama — jadi satu-satunya pertanyaan adalah mana yang cocok dengan cara kerja Anda.

<Frame>
  ![Empat cara menggunakan Flatkey, ditampilkan di Flatkey Console](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  Anda tidak harus memilih satu untuk selamanya. Mulailah dengan opsi yang paling mendekati apa yang sedang Anda kerjakan hari ini, dan tambahkan yang lain nanti menggunakan kunci yang sama.
</Tip>

## Sebelum Anda mulai

Buat kunci di [console.flatkey.ai/keys](https://console.flatkey.ai/keys). Kunci Flatkey diawali dengan `sk-`. Setiap opsi di bawah ini menggunakan satu kunci tersebut, jadi simpan di variabel lingkungan dan jauhkan dari kontrol sumber (source control).

Setiap panel di Console juga memungkinkan Anda memilih kunci yang sudah ada alih-alih membuat kunci baru, dan langsung memasukkannya ke dalam cuplikan (snippet) yang ditampilkan.

## API untuk pengembang

Panggil model apa pun melalui HTTP biasa dengan permintaan yang kompatibel dengan OpenAI. Tanpa SDK, tanpa dependensi — jika Anda memiliki klien HTTP, Anda sudah siap.

<Frame>
  ![Panel API untuk pengembang, dengan permintaan yang siap dijalankan](/images/quickstart/modal-api.png)
</Frame>

Console membuatkan permintaan untuk Anda: pilih kunci, pilih model, lalu salin cuplikan dalam **cURL**, **Node.js**, atau **Python**.

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## SDK untuk pengembang

Tetap gunakan OpenAI SDK yang sudah Anda pakai dan arahkan ke Flatkey. Kode permintaan Anda tidak berubah — hanya URL dasarnya yang berubah.

<Frame>
  ![Panel SDK untuk pengembang, dengan pengaturan SDK](/images/quickstart/modal-sdk.png)
</Frame>

Ide yang sama seperti di atas: pilih kunci dan model, lalu salin pengaturan untuk bahasa pemrograman Anda.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## Flatkey CLI

Hasilkan gambar dan video dari terminal Anda, atau biarkan asisten AI menjalankan CLI untuk Anda.

<Frame>
  ![Panel Flatkey CLI, menampilkan instalasi, masuk, dan prompt pertama](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="Instal">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="Masuk">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="Mulai membuat">
    Minta asisten AI Anda untuk membuat apa yang Anda inginkan, dan biarkan CLI-nya berjalan:

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

<Card title="Flatkey CLI dengan Agen AI" icon="terminal" href="/id/guides/flatkey-cli">

## Codex & Claude Code

Hubungkan agen coding Anda sekali, lalu gunakan Flatkey dari proyek-proyek yang sudah Anda buka.

<Frame>
  ![Panel Codex dan Claude Code, dengan perintah instalasi](/images/quickstart/modal-agents.png)
</Frame>

Console memberi Anda satu perintah instalasi untuk **macOS**, **Linux**, atau **Windows**. Perintah ini akan menginstal agen jika Anda belum memilikinya, meminta kunci Anda, dan menuliskan konfigurasinya untuk Anda.

<Warning>
  Installer bersifat interaktif. Ia akan menanyakan apakah Anda ingin menggunakan Claude Code atau Codex CLI, dan memerlukan Node.js yang sudah terinstal.
</Warning>

## Pastikan berhasil

Apa pun opsi yang Anda pilih, buka **Usage Logs** di [Console](https://console.flatkey.ai) setelah permintaan pertama Anda. Anda akan melihatnya terdaftar dengan model, jumlah token, latensi, dan biaya.

![Gunakan filter Model Name di Flatkey Usage Logs](/images/quickstart/flatkey-usage-logs.png)

Jika tidak ada yang muncul, tunggu beberapa detik dan cari lagi, lalu pastikan kunci API dan URL dasar yang sebenarnya digunakan oleh permintaan tersebut.

Buat permintaan Flatkey pertama Anda dalam sekitar lima menit. Anda memerlukan satu kunci API dan URL dasar yang kompatibel dengan OpenAI `https://router.flatkey.ai/v1`.

<Tip>
  Sudah menggunakan SDK OpenAI? Pertahankan kode permintaan Anda dan ubah URL dasar ke `https://router.flatkey.ai/v1`.
</Tip>

## Sebelum memulai

Anda memerlukan:

- Sebuah [akun Flatkey](https://console.flatkey.ai/sign-up)
- cURL, Python 3.10+, Node.js 22+, atau PowerShell
- Kredit prabayar untuk permintaan model

<Steps>
  <Step title="Siapkan akun dan kunci API Anda">
    Masuk ke [Konsol Flatkey](https://console.flatkey.ai). Buka **Dompet** dan pilih paket prabayar yang sesuai dengan kebutuhan Anda.

    ![Pilih paket prabayar di Dompet Flatkey](/images/quickstart/flatkey-top-up.png)

    Selanjutnya, buka **Kunci API** dan pilih **Buat Kunci API**.

    ![Buka Kunci API dan pilih Buat Kunci API](/images/quickstart/flatkey-api-keys.png)

    Beri nama yang jelas pada kunci tersebut. Anda juga dapat menetapkan batas kredit dan waktu kedaluwarsa sebelum memilih **Simpan perubahan**.

    ![Konfigurasikan nama, batas kredit, dan kedaluwarsa untuk kunci API Flatkey](/images/quickstart/flatkey-create-api-key.png)

    Salin rahasia yang dihasilkan dan simpan dengan aman. Kunci API Flatkey dimulai dengan `sk-fk-`.

    <Warning>
      Jangan pernah menyimpan kunci API di kontrol sumber atau mengeksposnya dalam kode sisi browser. Gunakan variabel lingkungan atau manajer rahasia.
    </Warning>
  </Step>

  <Step title="Kirim permintaan pertama Anda">
    Setel kunci API di shell Anda saat ini:

    <CodeGroup>
    ```bash macOS and Linux
    export FLATKEY_API_KEY="sk-fk-..."
    ```
    ```powershell Windows PowerShell
    $env:FLATKEY_API_KEY="sk-fk-..."
    ```
    </CodeGroup>

    Untuk Python, instal SDK OpenAI dengan `pip install openai`. Untuk TypeScript, jalankan `npm install openai`. cURL dan PowerShell tidak memerlukan SDK.

    Contoh-contoh berikut memanggil model yang sama melalui endpoint Flatkey yang sama:

    <CodeGroup>
    ```bash cURL
    curl https://router.flatkey.ai/v1/chat/completions \
      -H "Authorization: Bearer $FLATKEY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-4o-mini",
        "messages": [
          {"role": "user", "content": "Hello! What can you do?"}
        ]
      }'
    ```
    ```python Python
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ["FLATKEY_API_KEY"],
        base_url="https://router.flatkey.ai/v1",
    )

    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "user", "content": "Hello! What can you do?"}
        ],
    )

    print(response.choices[0].message.content)
    ```
    ```typescript TypeScript
    import OpenAI from "openai";

    const client = new OpenAI({
      apiKey: process.env.FLATKEY_API_KEY,
      baseURL: "https://router.flatkey.ai/v1",
    });

    const response = await client.chat.completions.create({
      model: "gpt-4o-mini",
      messages: [
        { role: "user", content: "Hello! What can you do?" },
      ],
    });

    console.log(response.choices[0].message.content);
    ```
    ```powershell PowerShell
    $headers = @{
      Authorization = "Bearer $env:FLATKEY_API_KEY"
      "Content-Type" = "application/json"
    }

    $body = @{
      model = "gpt-4o-mini"
      messages = @(
        @{ role = "user"; content = "Hello! What can you do?" }
      )
    } | ConvertTo-Json -Depth 4

    $response = Invoke-RestMethod `
      -Uri "https://router.flatkey.ai/v1/chat/completions" `
      -Method Post `
      -Headers $headers `
      -Body $body

    $response.choices[0].message.content
    ```
    </CodeGroup>

    Setelah permintaan selesai, buka **Log Penggunaan** di Konsol Flatkey. Masukkan `gpt-4o-mini` di **Nama Model** dan pilih **Cari**. Tangkapan layar menunjukkan tempat menerapkan filter; permintaan Anda yang telah selesai seharusnya muncul di tabel dengan jumlah token, latensi, dan biaya.

    ![Gunakan filter Nama Model di Log Penggunaan Flatkey](/images/quickstart/flatkey-usage-logs.png)

    Jika tabel masih menampilkan **Tidak Ada Log Ditemukan**, tunggu beberapa detik dan cari lagi. Jika tetap kosong, konfirmasikan kunci API dan URL Dasar yang digunakan oleh permintaan.
  </Step>

## Baca responsnya

Untuk respons Chat Completions, kolom yang paling sering Anda gunakan adalah:

- `choices[0].message.content` — teks yang dihasilkan
- `model` — model yang menangani permintaan
- `usage` — jumlah token prompt, penyelesaian, dan total

Lihat [referensi Chat Completions](/id/api-reference/chat-completions) untuk skema lengkapnya.

## Streaming respons

Setel `stream` ke `true` jika Anda menginginkan token saat dihasilkan.

Contoh Python dan TypeScript menggunakan kembali `client` yang Anda buat di **Kirim permintaan pertama Anda**.

<CodeGroup>
```bash cURL
curl --no-buffer https://router.flatkey.ai/v1/chat/completions \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "Write a two-line welcome message."}
    ],
    "stream": true
  }'
```
```python Python
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "Write a two-line welcome message."}
    ],
    stream=True,
)

for chunk in stream:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```
```typescript TypeScript
const stream = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [
    { role: "user", content: "Write a two-line welcome message." },
  ],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```
</CodeGroup>

## Menangani kesalahan umum

| Status HTTP | Arti umumnya | Yang harus dilakukan |
|---|---|---|
| `401` | Kunci API hilang, tidak valid, atau dicabut | Periksa header `Authorization: Bearer` dan buat kunci baru jika diperlukan |
| `401 insufficient_balance` | Saldo prabayar kosong | Tambahkan kredit dari **Dompet** |
| `503 model_not_found` | ID model salah eja atau tidak tersedia | Periksa [Direktori Model](https://flatkey.ai/models) untuk ID yang tepat. Mencoba ulang tidak akan membantu |
| `429` | Permintaan melebihi batas kecepatan | Coba ulang dengan backoff eksponensial dan jitter |
| `500` atau `503` | Penyedia atau rute sedang tidak tersedia sementara | Baca `error.code` di isi respons terlebih dahulu. Coba ulang dengan backoff dan periksa [Kesehatan Model](https://flatkey.ai/status) |

<Note>
  `503` bisa berarti gangguan sementara atau ID model yang tidak dikenal. Baca `error.code` di isi respons sebelum Anda mencoba ulang.
</Note>

Lihat [Kesalahan API](/id/api-reference/errors) untuk format respons dan detail pemecahan masalah.

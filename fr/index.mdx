## Comment fonctionne Flatkey

<Steps>
  <Step title="Créez votre compte">
    Inscrivez-vous sur [console.flatkey.ai](https://console.flatkey.ai/sign-up) et choisissez l'abonnement adapté à votre usage.
  </Step>
  <Step title="Générez une clé API">
    Ouvrez la section **Clés** dans le tableau de bord et créez une nouvelle clé API. Gardez-la secrète — traitez-la comme un mot de passe.
  </Step>
  <Step title="Pointez votre client vers Flatkey">
    Définissez `base_url` sur `https://router.flatkey.ai/v1` dans votre SDK compatible OpenAI. Aucune autre modification de code n'est nécessaire.
  </Step>
  <Step title="Suivez l'utilisation et les coûts">
    Suivez chaque requête, le nombre de tokens et les dépenses dans le tableau de bord **Utilisation**. Définissez des quotas pour plafonner vos dépenses.
  </Step>
</Steps>

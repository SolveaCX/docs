Flatkey vous donne une clé et quatre façons de l'utiliser. Ces quatre options partagent le même compte, le même solde et le même catalogue de modèles — la seule question est donc de savoir laquelle correspond le mieux à votre façon de travailler.

<Frame>
  ![Les quatre façons d'utiliser Flatkey, présentées dans la Console Flatkey](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  Vous n'avez pas à faire un choix définitif. Commencez par l'option la plus proche de ce que vous faites aujourd'hui, puis ajoutez les autres plus tard avec la même clé.
</Tip>

## Avant de commencer

Créez une clé sur [console.flatkey.ai/keys](https://console.flatkey.ai/keys). Les clés Flatkey commencent par `sk-`. Chaque option ci-dessous utilise cette même clé, alors conservez-la dans une variable d'environnement et hors du contrôle de version.

Chaque panneau de la Console vous permet également de choisir une clé existante plutôt que d'en créer une nouvelle, et l'insère directement dans l'extrait de code affiché.

## API pour les développeurs

Appelez n'importe quel modèle via une simple requête HTTP compatible avec OpenAI. Pas de SDK, pas de dépendances — si vous avez un client HTTP, vous êtes prêt.

<Frame>
  ![Le panneau API pour les développeurs, avec une requête prête à l'emploi](/images/quickstart/modal-api.png)
</Frame>

La Console construit la requête pour vous : choisissez une clé, choisissez un modèle, et copiez l'extrait en **cURL**, **Node.js** ou **Python**.

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## SDKs pour les développeurs

Conservez le SDK OpenAI que vous utilisez déjà et pointez-le vers Flatkey. Votre code de requête ne change pas — seule l'URL de base change.

<Frame>
  ![Le panneau SDKs pour les développeurs, avec la configuration du SDK](/images/quickstart/modal-sdk.png)
</Frame>

Même principe que ci-dessus : choisissez une clé et un modèle, puis copiez la configuration correspondant à votre langage.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## CLI Flatkey

Générez des images et des vidéos depuis votre terminal, ou laissez un assistant IA piloter la CLI pour vous.

<Frame>
  ![Le panneau CLI Flatkey, montrant l'installation, la connexion et la première invite](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="Installer">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="Se connecter">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="Commencer à créer">
    Demandez à votre assistant IA ce que vous voulez, et laissez-le exécuter la CLI :

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

<Card title="Flatkey CLI avec un agent IA" icon="terminal" href="/fr/guides/flatkey-cli">
  Commandes, sortie JSON pour les agents et récupération après erreur.
</Card>

## Codex & Claude Code

Connectez votre agent de code une seule fois, puis utilisez Flatkey depuis les projets que vous avez déjà ouverts.

<Frame>
  ![Le panneau Codex et Claude Code, avec la commande d'installation](/images/quickstart/modal-agents.png)
</Frame>

La Console vous fournit une seule commande d'installation pour **macOS**, **Linux** ou **Windows**. Elle installe l'agent si vous ne l'avez pas déjà, vous demande votre clé, et écrit la configuration à votre place.

<Warning>
  L'installateur est interactif. Il vous demande si vous voulez Claude Code ou Codex CLI, et nécessite que Node.js soit déjà installé.
</Warning>

## Vérifiez que tout fonctionne

Quelle que soit l'option choisie, ouvrez **Usage Logs** dans la [Console](https://console.flatkey.ai) après votre première requête. Vous devriez la voir apparaître avec le modèle, le nombre de tokens, la latence et le coût.

![Utilisez le filtre Model Name dans les journaux d'utilisation Flatkey](/images/quickstart/flatkey-usage-logs.png)

Si rien n'apparaît, attendez quelques secondes et effectuez une nouvelle recherche, puis vérifiez la clé API et l'URL de base réellement utilisées par la requête.

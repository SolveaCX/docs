Flatkey даёт вам один ключ и четыре способа его использовать. Все четыре варианта используют один и тот же аккаунт, один баланс и один каталог моделей — так что остаётся только выбрать, что подходит именно вам.

<Frame>
  ![Четыре способа использования Flatkey, показанные в Flatkey Console](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  Вам не нужно выбирать раз и навсегда. Начните с того варианта, который ближе всего к тому, что вы делаете сегодня, а остальные добавьте позже к тому же ключу.
</Tip>

## Прежде чем начать

Создайте ключ на [console.flatkey.ai/keys](https://console.flatkey.ai/keys). Ключи Flatkey начинаются с `sk-`. Каждый из вариантов ниже использует один и тот же ключ, поэтому храните его в переменной окружения и не добавляйте в систему контроля версий.

Каждая панель в Console также позволяет выбрать существующий ключ вместо создания нового и сразу подставляет его в показанный фрагмент кода.

## API для разработчиков

Вызывайте любую модель через обычный HTTP-запрос, совместимый с OpenAI. Никаких SDK, никаких зависимостей — если у вас есть HTTP-клиент, вы уже готовы.

<Frame>
  ![Панель API для разработчиков с готовым к запуску запросом](/images/quickstart/modal-api.png)
</Frame>

Console формирует запрос за вас: выберите ключ, выберите модель и скопируйте фрагмент кода на **cURL**, **Node.js** или **Python**.

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## SDK для разработчиков

Оставьте тот OpenAI SDK, которым вы уже пользуетесь, и направьте его на Flatkey. Код запросов не меняется — меняется только базовый URL.

<Frame>
  ![Панель SDK для разработчиков с настройкой SDK](/images/quickstart/modal-sdk.png)
</Frame>

Та же идея, что и выше: выберите ключ и модель, затем скопируйте настройку для вашего языка программирования.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## Flatkey CLI

Генерируйте изображения и видео прямо из терминала или позвольте AI-ассистенту управлять CLI за вас.

<Frame>
  ![Панель Flatkey CLI с установкой, входом в систему и первым запросом](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="Установка">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="Вход в систему">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="Начните создавать">
    Попросите своего AI-ассистента о том, что вам нужно, и позвольте ему запустить CLI:

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

## Codex и Claude Code

Подключите своего кодинг-агента один раз, а затем используйте Flatkey в уже открытых проектах.

<Frame>
  ![Панель Codex и Claude Code с командой установки](/images/quickstart/modal-agents.png)
</Frame>

Console предоставляет единую команду установки для **macOS**, **Linux** или **Windows**. Она устанавливает агента, если его у вас ещё нет, запрашивает ваш ключ и записывает конфигурацию за вас.

<Warning>
  Установщик интерактивный. Он спрашивает, хотите ли вы использовать Claude Code или Codex CLI, и требует, чтобы Node.js уже был установлен.
</Warning>

## Проверьте, что всё сработало

Какой бы вариант вы ни выбрали, откройте **Usage Logs** в [Console](https://console.flatkey.ai) после первого запроса. Вы должны увидеть его в списке с указанием модели, количества токенов, задержки и стоимости.

![Используйте фильтр по названию модели в журналах использования Flatkey](/images/quickstart/flatkey-usage-logs.png)

Если ничего не появилось, подождите несколько секунд и выполните поиск снова, а затем проверьте, какой API-ключ и базовый URL фактически использовались в запросе.

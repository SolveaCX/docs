## Как это работает

Flatkey располагается между вашим приложением и AI-провайдерами. При отправке запроса:

1. Ваш клиент обращается к `https://router.flatkey.ai/v1` с вашим API-ключом Flatkey.
2. Flatkey аутентифицирует запрос и списывает стоимость с вашего предоплатного баланса.
3. Запрос перенаправляется к официальному API провайдера (OpenAI, Anthropic и т.д.).
4. Ответ возвращается напрямую вашему клиенту — без каких-либо преобразований содержимого.

Промпты и ответы никогда не сохраняются. Flatkey фиксирует только метаданные (модель, количество токенов, временны́е метки) для биллинга и аналитики.

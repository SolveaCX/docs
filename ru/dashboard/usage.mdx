Панель **Использование** Flatkey даёт полную видимость каждого запроса к API, выполненного с вашего аккаунта. Каждая запись журнала показывает использованную модель, количество входных и выходных токенов, стоимость, списанную с баланса, и временну́ю метку. Используйте этот раздел для анализа паттернов расходов, отладки ошибок и сверки затрат.

## Доступ к журналам использования

<Steps>
  <Step title="Откройте консоль">
    Войдите на [console.flatkey.ai](https://console.flatkey.ai) и нажмите **Использование** в левой боковой панели.
  </Step>
  <Step title="Задайте диапазон дат">
    Используйте выбор даты вверху, чтобы фильтровать журналы по дню, неделе, месяцу или произвольному диапазону. По умолчанию отображаются последние 7 дней.
  </Step>
  <Step title="Фильтрация по модели или ключу">
    Используйте выпадающие списки **Модель** и **API-ключ**, чтобы сосредоточиться на конкретной модели или ключе. Это удобно для сравнения расходов между моделями или аудита отдельной интеграции.
  </Step>
</Steps>

## Что показывает каждая запись журнала

| Поле | Описание |
|---|---|
| **Временна́я метка** | Когда запрос был получен Flatkey |
| **Модель** | Использованный идентификатор модели (например, `gpt-4o-mini`, `claude-sonnet-4-5`) |
| **Входные токены** | Количество токенов в запросе |
| **Выходные токены** | Количество токенов в ответе |
| **Стоимость** | Сумма, списанная с вашего баланса за этот запрос |
| **API-ключ** | Какой ключ использовался (отображается как имя + маскированный префикс) |
| **Статус** | Успешно или неудачно выполнен запрос |

## Понимание расходов

Каждый запрос показывает фактически начисленную стоимость, которая отражает:
- Цену входных и выходных токенов модели (по сниженному тарифу Flatkey)
- Ваш текущий бонус за пополнение, применяемый автоматически

Сумма стоимостей всех запросов равна общему потреблённому балансу за этот период.

## Мониторинг баланса

Ваш текущий баланс отображается вверху страницы Использование и в разделе **Баланс**. Когда баланс опускается ниже установленного вами порога, вы получите уведомление по электронной почте. Для настройки уведомлений перейдите в **Настройки → Уведомления**.

<Note>
  Баланс списывается в режиме реального времени по мере выполнения запросов. Если запрос завершился ошибкой на стороне провайдера, стоимость может быть частично списана в зависимости от того, сколько токенов было обработано до сбоя.
</Note>

## Экспорт журналов

Для экспорта данных об использовании:
1. Задайте нужный диапазон дат и фильтры.
2. Нажмите **Экспорт** в правом верхнем углу.
3. Выберите формат CSV или JSON.
4. Файл загрузится в ваш браузер.

Экспортированные журналы содержат все поля, показанные в панели управления, и подходят для загрузки в таблицы или финансовые инструменты.

## Оповещения о высоком использовании

Чтобы предотвратить неконтролируемые расходы:
- Установите **ежемесячный лимит расходов** в **Настройки → Биллинг** — запросы блокируются после достижения лимита.
- Используйте **Группы** для установки квот на ключ или приложение.

<Tip>
  В процессе разработки используйте отдельный ключ с установленной квотой расходов на небольшую сумму (например, $5). Это предотвратит случайные запросы с высокой стоимостью, которые могут истощить ваш рабочий баланс.
</Tip>

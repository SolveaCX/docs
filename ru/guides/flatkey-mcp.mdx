MCP-сервер Flatkey даёт любому MCP-клиенту пять инструментов для генерации изображений и видео. Вы добавляете его один раз, а затем просите ассистента сделать изображение или ролик обычными словами. Сервер работает на вашем компьютере и обращается к Flatkey с вашим собственным API-ключом.

<CardGroup cols={2}>
  <Card title="Терминал не нужен" icon="plug">
    Работает в клиентах, которые не умеют выполнять команды терминала, например в Claude Desktop.
  </Card>
  <Card title="Один ключ, один баланс" icon="key">
    Использует тот же API-ключ и те же кредиты, что API и Flatkey CLI.
  </Card>
</CardGroup>

## Что потребуется

- Node.js 20 или новее
- API-ключ Flatkey (`sk-fk-...`). Создайте его в [консоли Flatkey](https://console.flatkey.ai/keys)

## Добавьте сервер в клиент

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add flatkey -e FLATKEY_API_KEY=sk-fk-your-flatkey-key -- npx -y @flatkey-ai/mcp
    ```
  </Tab>
  <Tab title="Claude Desktop">
    Откройте **Settings**, затем **Developer**, затем **Edit Config**. Добавьте сервер и перезапустите приложение.

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "flatkey": {
          "command": "npx",
          "args": ["-y", "@flatkey-ai/mcp"],
          "env": { "FLATKEY_API_KEY": "sk-fk-your-flatkey-key" }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Cursor">
    ```json .cursor/mcp.json
    {
      "mcpServers": {
        "flatkey": {
          "command": "npx",
          "args": ["-y", "@flatkey-ai/mcp"],
          "env": { "FLATKEY_API_KEY": "sk-fk-your-flatkey-key" }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Codex">
    ```toml ~/.codex/config.toml
    [mcp_servers.flatkey]
    command = "npx"
    args = ["-y", "@flatkey-ai/mcp"]
    env = { FLATKEY_API_KEY = "sk-fk-your-flatkey-key" }
    ```
  </Tab>
</Tabs>

## Создайте первое изображение

Попросите ассистента:

```text
Сгенерируй предметное фото 16:9: матовая чёрная бутылка для воды на мокром камне,
и сохрани его в ~/Pictures/bottle.png
```

Ассистент вызовет `generate_image` и сообщит путь к сохранённому файлу. Чтобы проверить подключение, не тратя кредиты, попросите его перечислить ваши видеомодели Flatkey или показать баланс кредитов.

## Инструменты

| Инструмент | Что делает | Тратит кредиты |
| --- | --- | --- |
| `generate_image` | Текст в изображение. Передайте `reference_images`, чтобы отредактировать изображение или сменить стиль | Да |
| `generate_video` | Текст в видео, изображение в видео, первый и последний кадр, референсные видео | Да |
| `get_video` | Проверяет видео, которое ещё рендерится, и возвращает результат | Нет |
| `list_models` | Показывает идентификаторы моделей, доступных вашему ключу, с фильтром `image`, `video`, `audio` или `text` | Нет |
| `get_credits` | Показывает остаток на балансе | Нет |

### Параметры изображения

| Параметр | Значение |
| --- | --- |
| `prompt` | Что должно быть на изображении. Обязательный |
| `model` | Идентификатор модели изображений. По умолчанию `gpt-image-2` |
| `reference_images` | URL или пути к локальным файлам изображений, которые нужно отредактировать или взять за образец |
| `size`, `n`, `quality` | Только для `gpt-image-2` |
| `output_format` | `png`, `jpeg`, `webp` или `gif`. Только для моделей изображений GPT |
| `save_to` | Файл или папка для сохранения результата |

О моделях и их API читайте в разделе [Генерация изображений](/ru/guides/image-generation).

### Параметры видео

| Параметр | Значение |
| --- | --- |
| `prompt` | Что происходит в видео. Обязательный |
| `model` | Идентификатор видеомодели. По умолчанию `seedance-2.0-pro` |
| `duration` | Длительность в секундах |
| `ratio` | `16:9`, `9:16`, `4:3`, `3:4`, `21:9`, `1:1` или `adaptive` |
| `resolution` | Допустимые значения зависят от модели |
| `first_frame`, `last_frame` | Изображение для начала и изображение для конца |
| `reference_images` | Изображения, которым должно следовать видео |
| `reference_videos` | Видео, задающие движение. Только для моделей Seedance |
| `wait_seconds` | Сколько ждать готовое видео. По умолчанию 45 |
| `save_to` | Файл или папка для сохранения MP4 |

<Warning>
  Значения разрешения не общие для всех моделей. `seedance-2.5` отклоняет `1080p`, а `MiniMax-H3` принимает только `768P` и `2K`. См. [Генерация видео](/ru/guides/video-generation).
</Warning>

## Как устроена генерация видео

Видео создаётся асинхронно, и пятисекундный ролик обычно занимает от двух до четырёх минут. `generate_video` отправляет задачу и ждёт до `wait_seconds` секунд. Если ролик ещё рендерится, инструмент возвращает идентификатор задачи:

```json
{
  "status": "processing",
  "task_id": "task_aaaaaaaaaaaaaaaa",
  "model": "seedance-2.0-pro",
  "next": "The video is still rendering. Call get_video with task_id \"task_aaaaaaaaaaaaaaaa\" in about 30 seconds."
}
```

Затем ассистент вызывает `get_video`, пока статус не станет `completed`:

```json
{
  "status": "completed",
  "task_id": "task_aaaaaaaaaaaaaaaa",
  "videos": [
    {
      "url": "https://router.flatkey.ai/v1/videos/task_aaaaaaaaaaaaaaaa/content",
      "path": "/Users/you/flatkey-output/flatkey-video-20261124T091500.mp4"
    }
  ]
}
```

Если ассистент остановился после первого вызова, попросите его проверить видео ещё раз. Проверка не тратит кредиты.

## Куда сохраняются файлы

- **Видео** всегда сохраняются на диск, а в результате указан путь к файлу. Они попадают в `save_to`, в `FLATKEY_OUTPUT_DIR` или в `~/flatkey-output`.
- **Изображения** возвращаются в виде временной ссылки. Передайте `save_to`, чтобы сохранить копию, или задайте `FLATKEY_OUTPUT_DIR`, чтобы складывать все результаты в одну папку.
- **Локальные файлы-референсы** перед генерацией загружаются во временное хранилище Flatkey. Изображения: `png`, `jpg`, `webp` или `gif`. Видео: `mp4` или `mov`.

Задайте `FLATKEY_OUTPUT_DIR` в том же блоке `env`, что и API-ключ:

```json
"env": {
  "FLATKEY_API_KEY": "sk-fk-your-flatkey-key",
  "FLATKEY_OUTPUT_DIR": "~/Pictures/flatkey"
}
```

## Ограничения, которые проверяет сервер

Сервер отклоняет медиафайлы, которые модель не может использовать, ещё до отправки запроса, поэтому запрос не тратит кредиты.

| Модель | Ограничение |
| --- | --- |
| Модели Veo | Одно входное изображение, оно становится первым кадром. Последний кадр не поддерживается |
| Модели, кроме Seedance и `MiniMax-H3` | Референсные видео не поддерживаются |
| Seedance 2.5 | До 30 референсных изображений и 10 референсных видео |
| Остальные модели | До 5 референсных изображений |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| `Missing or invalid Flatkey API key` | Проверьте `FLATKEY_API_KEY` в конфигурации клиента и перезапустите клиент |
| `No available channel for model ...` | Модель сейчас не маршрутизируется. Попросите ассистента вызвать `list_models` и выбрать другую |
| `unsupported resolution` | Укажите значение, которое принимает модель, или не передавайте `resolution` |
| Недостаточно кредитов | Узнайте баланс через `get_credits` и пополните его в [консоли Flatkey](https://console.flatkey.ai) |
| Видео так и не приходит | Попросите ассистента вызвать `get_video` с полученным идентификатором задачи |
| Клиент не показывает инструменты | Убедитесь командой `node --version`, что установлен Node.js 20 или новее, и перезапустите клиент |

<Note>
  Удобнее в терминале? [Flatkey CLI](/ru/guides/flatkey-cli) даёт ту же генерацию в виде команд, а также аудио.
</Note>

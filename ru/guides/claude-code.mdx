Claude Code от Anthropic — это агентный AI-ассистент для программирования, работающий в вашем терминале. Установив переменную среды `ANTHROPIC_BASE_URL`, вы можете направлять все запросы Claude Code через Flatkey и платить по сниженным тарифам Flatkey за использование моделей Claude.

## Предварительные требования

- Claude Code установлен: `npm install -g @anthropic-ai/claude-code`
- Аккаунт Flatkey с API-ключом — [получите его здесь](https://console.flatkey.ai/sign-up)

## Настройка

Установите следующие две переменные среды:

```bash
export ANTHROPIC_BASE_URL="https://router.flatkey.ai"
export ANTHROPIC_API_KEY="sk-fk-your-flatkey-key"
```

Чтобы сделать настройку постоянной, добавьте их в профиль вашей оболочки:

```bash ~/.zshrc
export ANTHROPIC_BASE_URL="https://router.flatkey.ai"
export ANTHROPIC_API_KEY="sk-fk-your-flatkey-key"
```

<Warning>
  Установите `ANTHROPIC_BASE_URL` в значение `https://router.flatkey.ai` — без завершающего `/v1`. Claude Code CLI автоматически добавляет правильный путь.
</Warning>

## Настройка с помощью CC Switch

[CC Switch](https://ccswitch.io) — это сторонний менеджер конфигурации для рабочего стола, предназначенный для ассистентов программирования. Его также можно скачать из [официального репозитория GitHub](https://github.com/farion1231/cc-switch).

1. Откройте CC Switch и выберите **Claude Code**.
2. Добавьте **пользовательского провайдера** с именем `Flatkey`.
3. Укажите базовый URL `https://router.flatkey.ai` без завершающего `/v1`.
4. Введите ваш API-ключ Flatkey (`sk-fk-...`) и активируйте провайдера.
5. Полностью закройте и снова откройте Claude Code, чтобы перезагрузить настройки провайдера.
6. Отправьте небольшой запрос, а затем проверьте его в разделе **Журнал использования** в [консоли Flatkey](https://console.flatkey.ai/usage-logs/common).

<Note>
  Если ваша версия CC Switch не включает предустановку Flatkey, используйте **пользовательского провайдера**. CC Switch не является продуктом Flatkey.
</Note>

## Запуск Claude Code

Используйте Claude Code так же, как обычно:

```bash
claude "Fix the bug in this file"
```

или в интерактивном режиме:

```bash
claude
```

Все запросы направляются через Flatkey и списываются с вашего предоплаченного баланса по сниженным тарифам.

## Проверка настройки

Выполните простой запрос, а затем проверьте **Журнал использования** в вашей [консоли Flatkey](https://console.flatkey.ai/usage-logs/common). Вы должны увидеть запрос Claude с идентификатором модели, количеством токенов и стоимостью.

## Оценка экономии

Использование Claude Sonnet (популярный выбор для Claude Code) через Flatkey:

| | Официальная цена | Flatkey (после бонуса $200) |
|---|---|---|
| Входные токены `claude-sonnet-4-5` | $3 / 1M токенов | ~$1.6 / 1M токенов |
| Входные токены `claude-haiku-4-5-20251001` | $1 / 1M токенов | ~$0.53 / 1M токенов |

В типичной сессии Claude Code с 50K входными токенами при использовании Sonnet это составит:
- Официально: ~$0.15 за сессию
- Flatkey: ~$0.08 за сессию

<Tip>
  Активные пользователи Claude Code получают наибольшую выгоду от уровня пополнения на $200 — бонусный кредит фактически даёт вам дополнительный месяц использования сверх скидки на модель.
</Tip>

## Устранение неполадок

| Проблема | Решение |
|---|---|
| `Authentication failed` | Убедитесь, что `ANTHROPIC_API_KEY` — это ваш ключ Flatkey (`sk-fk-...`) |
| `Could not connect` | Проверьте, что `ANTHROPIC_BASE_URL` установлен в `https://router.flatkey.ai` |
| `Insufficient balance` | Пополните баланс на [console.flatkey.ai](https://console.flatkey.ai) |
| Запросы отсутствуют в панели управления | Проверьте, что переменные среды экспортированы в текущей оболочке |

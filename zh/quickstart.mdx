Flatkey 为你提供一个密钥和四种使用方式。这四种方式共享同一个账户、同一个余额和同一个模型目录——因此唯一的问题是哪一种更适合你的工作方式。

<Frame>
  ![Flatkey 控制台中展示的四种使用 Flatkey 的方式](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  你不必一次性做出最终选择。先从最贴近你当前工作的方式开始，之后再用同一个密钥添加其他方式。
</Tip>

## 开始之前

在 [console.flatkey.ai/keys](https://console.flatkey.ai/keys) 创建一个密钥。Flatkey 密钥以 `sk-` 开头。下面的每个选项都使用这同一个密钥，因此请把它保存在环境变量中，不要提交到源代码管理中。

控制台中的每个面板也允许你选择一个已有的密钥，而不必新建一个，并会将它直接填入展示给你的代码片段中。

## 面向开发者的 API

使用兼容 OpenAI 的请求，通过普通 HTTP 调用任意模型。无需 SDK，无需依赖——只要你有 HTTP 客户端，就可以开始使用。

<Frame>
  ![面向开发者的 API 面板，展示了可直接运行的请求](/images/quickstart/modal-api.png)
</Frame>

控制台会为你构建请求：选择一个密钥，选择一个模型，然后复制以 **cURL**、**Node.js** 或 **Python** 形式提供的代码片段。

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## 面向开发者的 SDK

继续使用你已经在用的 OpenAI SDK，只需将其指向 Flatkey。你的请求代码不需要改动——只有基础 URL 需要更改。

<Frame>
  ![面向开发者的 SDK 面板，展示了 SDK 的配置方式](/images/quickstart/modal-sdk.png)
</Frame>

思路与上面相同：选择一个密钥和一个模型，然后复制适用于你所用语言的配置代码。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## Flatkey CLI

从终端生成图像和视频，或者让 AI 助手为你操作该 CLI。

<Frame>
  ![Flatkey CLI 面板，展示了安装、登录以及首个提示词](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="安装">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="登录">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="开始创作">
    向你的 AI 助手说出你想要的内容，让它来运行该 CLI：

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

## Codex 与 Claude Code

只需连接一次你的编程智能体，之后即可在你已经打开的项目中直接使用 Flatkey。

<Frame>
  ![Codex 与 Claude Code 面板，展示了安装命令](/images/quickstart/modal-agents.png)
</Frame>

控制台会为你提供一条适用于 **macOS**、**Linux** 或 **Windows** 的单一安装命令。如果你还没有安装该智能体，它会自动安装，询问你的密钥，并为你写入配置。

<Warning>
  该安装程序是交互式的。它会询问你想要 Claude Code 还是 Codex CLI，并且需要预先安装好 Node.js。
</Warning>

## 检查是否成功

无论你选择了哪种方式，在发出第一个请求后，都可以打开[控制台](https://console.flatkey.ai)中的 **Usage Logs**（使用日志）。你应该能看到该请求被列出，包括模型、token 数量、延迟以及费用。

![在 Flatkey 使用日志中使用模型名称筛选器](/images/quickstart/flatkey-usage-logs.png)

如果没有出现任何内容，等待几秒后再次搜索，然后确认该请求实际使用的 API 密钥和基础 URL。

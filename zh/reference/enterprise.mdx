<Note>
  用量较大？请打开[联系页面](https://flatkey.ai/contact)，找到 **Enterprise** 方案并点击 **Contact sales**。企业合同涵盖承诺用量折扣、定制路由、账单结算和采购支持。
</Note>

自助方案可以覆盖大多数个人和小团队的用量。当用量、付款方式或采购流程超出自助方案的范围时，就可以考虑企业合同。

## 合同与计费

<Accordion title="什么时候应该转为企业合同？">
  当用量超出自助方案的覆盖范围、团队需要账单结算而非刷卡付款，或采购流程要求签署正式合同时，可以考虑企业合同。如果不确定，把每月 Token 用量和目标模型发给 [support@flatkey.ai](mailto:support@flatkey.ai)。
</Accordion>

<Accordion title="企业合同包含哪些内容？">
  企业版采用定制价格。合同涵盖承诺用量折扣、定制路由、账单结算和采购支持。具体条款取决于你的用量和模型组合，详见[价格页面](https://flatkey.ai/pricing)的 **Enterprise** 方案。
</Accordion>

<Accordion title="Flatkey 支持账单结算吗？">
  支持。企业账号支持账单结算、自定义月度用量、团队采购和专属路由折扣。请联系 [support@flatkey.ai](mailto:support@flatkey.ai) 了解条款。
</Accordion>

## 团队与访问控制

<Accordion title="多个成员可以共用一个企业账号吗？">
  可以。为每个成员或每个服务单独创建 API 密钥，再用 **分组** 为每个密钥设置模型访问策略和支出额度。每次请求都会带着所属密钥出现在 **用量日志** 中，因此可以按团队或项目归集费用。
</Accordion>

<Accordion title="可以限制密钥能访问的模型吗？">
  可以。在控制台中使用 **分组**，为单个密钥或密钥组设置模型访问策略和支出额度。
</Accordion>

## 安全评估

<Accordion title="做供应商安全评估需要提供什么？">
  请把评估问卷发送至 [support@flatkey.ai](mailto:support@flatkey.ai)。Flatkey 的数据留存和合规情况可参见常见问题中的[隐私和安全](/zh/reference/faq#隐私和安全)部分。
</Accordion>

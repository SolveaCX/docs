Das Flatkey **Nutzungs**-Dashboard bietet Ihnen vollständige Transparenz über jede API-Anfrage, die mit Ihrem Konto gestellt wurde. Jeder Protokolleintrag zeigt das verwendete Modell, die Anzahl der Ein- und Ausgabe-Token, die von Ihrem Guthaben abgezogenen Kosten sowie den Zeitstempel. Nutzen Sie diese Ansicht, um Ihre Ausgabenmuster zu verstehen, Fehler zu debuggen und Kosten abzustimmen.

## Zugriff auf Nutzungsprotokolle

<Steps>
  <Step title="Konsole öffnen">
    Melden Sie sich bei [console.flatkey.ai](https://console.flatkey.ai) an und klicken Sie in der linken Seitenleiste auf **Nutzung**.
  </Step>
  <Step title="Datumsbereich festlegen">
    Verwenden Sie die Datumsauswahl oben, um Protokolle nach Tag, Woche, Monat oder einem benutzerdefinierten Bereich zu filtern. Die Standardansicht zeigt die letzten 7 Tage.
  </Step>
  <Step title="Nach Modell oder Schlüssel filtern">
    Verwenden Sie die Dropdowns **Modell** und **API-Schlüssel**, um sich auf ein bestimmtes Modell oder einen bestimmten Schlüssel zu konzentrieren. Dies ist nützlich, um Kosten zwischen Modellen zu vergleichen oder eine bestimmte Integration zu prüfen.
  </Step>
</Steps>

## Was jeder Protokolleintrag anzeigt

| Feld | Beschreibung |
|---|---|
| **Zeitstempel** | Zeitpunkt, zu dem die Anfrage von Flatkey empfangen wurde |
| **Modell** | Die verwendete Modell-ID (z. B. `gpt-4o-mini`, `claude-sonnet-4-5`) |
| **Eingabe-Token** | Anzahl der Token in der Eingabeaufforderung |
| **Ausgabe-Token** | Anzahl der Token in der Vervollständigung |
| **Kosten** | Für diese Anfrage von Ihrem Guthaben abgezogener Betrag |
| **API-Schlüssel** | Welcher Schlüssel verwendet wurde (angezeigt als Name + maskiertes Präfix) |
| **Status** | Ob die Anfrage erfolgreich war oder fehlgeschlagen ist |

## Kosten verstehen

Jede Anfrage zeigt die tatsächlich berechneten Kosten, die Folgendes widerspiegeln:
- Den Eingabe- und Ausgabepreis des Modells (zum vergünstigten Flatkey-Tarif)
- Ihren aktuellen Aufladebonus, der automatisch angewendet wird

Die Summe aller Anfragekosten entspricht dem in diesem Zeitraum verbrauchten Gesamtguthaben.

## Guthaben überwachen

Ihr aktuelles Guthaben wird oben auf der Nutzungsseite und im Abschnitt **Guthaben** angezeigt. Wenn das Guthaben unter einen von Ihnen festgelegten Schwellenwert fällt, erhalten Sie eine E-Mail-Benachrichtigung. Um Benachrichtigungen zu konfigurieren, gehen Sie zu **Einstellungen → Benachrichtigungen**.

<Note>
  Das Guthaben wird in Echtzeit abgezogen, sobald Anfragen abgeschlossen sind. Wenn eine Anfrage auf Anbieterseite fehlschlägt, können die Kosten je nachdem, wie viele Token vor dem Fehler verarbeitet wurden, dennoch teilweise abgezogen werden.
</Note>

## Protokolle exportieren

So exportieren Sie Nutzungsdaten:
1. Legen Sie den gewünschten Datumsbereich und die Filter fest.
2. Klicken Sie oben rechts auf **Exportieren**.
3. Wählen Sie das Format CSV oder JSON.
4. Die Datei wird in Ihren Browser heruntergeladen.

Exportierte Protokolle enthalten alle im Dashboard angezeigten Felder und eignen sich zum Hochladen in Tabellenkalkulationen oder Finanz-Tools.

## Warnungen bei hoher Nutzung

Um unkontrollierte Ausgaben zu verhindern:
- Legen Sie ein **monatliches Ausgabenlimit** unter **Einstellungen → Abrechnung** fest — Anfragen werden blockiert, sobald das Limit erreicht ist.
- Verwenden Sie **Gruppen**, um pro Schlüssel oder pro Anwendung Kontingente festzulegen.

<Tip>
  Verwenden Sie während der Entwicklung einen separaten Schlüssel mit einem auf einen kleinen Betrag festgelegten Ausgabenkontingent (z. B. 5 $). Dies verhindert, dass versehentliche hochpreisige Anfragen Ihr Produktionsguthaben aufbrauchen.
</Tip>

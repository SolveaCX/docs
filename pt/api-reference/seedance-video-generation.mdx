Use `POST /v1/videos` para criar uma tarefa assíncrona de geração de vídeo Seedance. Consulte o status da tarefa até que ela seja concluída e, em seguida, baixe o vídeo pela URL do Flatkey retornada.

Os modelos suportados incluem `seedance-2.0` e `seedance-2.0-fast`. A disponibilidade depende da sua conta; use [`GET /v1/models`](/pt/api-reference/models) para obter a lista atual de modelos.

## Endpoint

```http
POST https://router.flatkey.ai/v1/videos
```

<Note>
  O Flatkey também aceita `POST /v1/video/generations` e `GET /v1/video/generations/{task_id}`. Use `/v1/videos` para a estrutura de resposta padrão e dados nativos de `usage`.
</Note>

## Requisição

### Cabeçalhos

| Cabeçalho | Valor |
|---|---|
| `Authorization` | `Bearer $FLATKEY_API_KEY` |
| `Content-Type` | `application/json` |

### Parâmetros do corpo

<ParamField body="model" type="string" required>
  ID do modelo Seedance. Use `"seedance-2.0"` ou `"seedance-2.0-fast"`.
</ParamField>

<ParamField body="content" type="array" required>
  Itens de entrada multimodal. Inclua pelo menos um item de texto não vazio, URL de imagem ou URL de vídeo.
</ParamField>

<ParamField body="resolution" type="string">
  Resolução de saída: `"480p"`, `"720p"` ou `"1080p"`.
</ParamField>

<ParamField body="ratio" type="string">
  Proporção de saída: `"16:9"`, `"4:3"`, `"1:1"`, `"3:4"`, `"9:16"`, `"21:9"` ou `"adaptive"`.
</ParamField>

<ParamField body="duration" type="integer">
  Duração do vídeo de 4 a 15 segundos. Use `-1` para deixar o modelo escolher.
</ParamField>

<ParamField body="seed" type="integer">
  Semente aleatória. Omita para usar uma semente aleatória.
</ParamField>

<ParamField body="watermark" type="boolean">
  Se deve adicionar uma marca d'água. Padrão: `false`.
</ParamField>

<ParamField body="generate_audio" type="boolean">
  Se deve gerar áudio sincronizado.
</ParamField>

### Itens de `content`

| `type` | Campo de valor | `role` suportado | Finalidade |
|---|---|---|---|
| `text` | `text` | — | Prompt de texto. Múltiplos itens de texto são concatenados em ordem. |
| `image_url` | `image_url.url` | `first_frame`, `last_frame`, `reference_image` | Imagem de entrada ou referência. Até 9 imagens. |
| `video_url` | `video_url.url` | `reference_video` | Vídeo de referência. Até 3 vídeos. |
| `audio_url` | `audio_url.url` | `reference_audio` | Áudio de referência. Até 3 clipes. |

Se uma imagem usar o papel `first_frame` ou `last_frame`, a API opera no modo de primeiro/último quadro. As demais imagens são tratadas como referências.

### Parâmetros avançados

<ParamField body="input_type" type="string">
  Modo de entrada explícito: `"reference"` ou `"first_last_frame"`. Omita para inferir o modo a partir de `content`.
</ParamField>

<ParamField body="web_search" type="boolean">
  Ativa o aprimoramento por busca na web para a tarefa.
</ParamField>

<ParamField body="super_resolution_config" type="object">
  Aumenta a resolução do vídeo gerado mantendo o mesmo ID de tarefa público.

  <Expandable title="Campos de super_resolution_config">
    <ParamField body="resolution" type="string">
      Resolução alvo: `"720p"`, `"1080p"`, `"2k"` ou `"4k"`. Deve ser maior que a resolução original e não pode ser combinado com `resolution_limit`.
    </ParamField>
    <ParamField body="resolution_limit" type="integer">
      Limite de pixels personalizado para a dimensão menor, de 64 a 2160. Não pode ser combinado com `resolution`.
    </ParamField>
    <ParamField body="scene" type="string">
      Cena de upscaling: `"aigc"`, `"short_series"`, `"ugc"` ou `"old_film"`.
    </ParamField>
    <ParamField body="tool_version" type="string">
      Modo de upscaling: `"standard"` (padrão) ou `"professional"`.
    </ParamField>
    <ParamField body="fps" type="integer">
      Taxa de quadros de saída de 1 a 120. Valores acima da taxa de quadros da fonte ativam a interpolação de quadros.
    </ParamField>
  </Expandable>
</ParamField>

<Warning>
  `camera_fixed`, `frames`, `callback_url` e `return_last_frame` são aceitos por compatibilidade, mas atualmente não têm efeito.
</Warning>

## Resposta

```json
{
  "id": "task_3f9a00000000000000000000000000e2",
  "task_id": "task_3f9a00000000000000000000000000e2",
  "object": "video",
  "model": "seedance-2.0",
  "status": "queued",
  "progress": 0,
  "created_at": 1780306574
}
```

### Campos da resposta

<ResponseField name="id" type="string">
  ID público da tarefa usado para consultar o status e baixar o vídeo concluído. `task_id` contém o mesmo valor.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa: `queued`, `in_progress`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Progresso da geração de 0 a 100.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Timestamp Unix da criação da tarefa.
</ResponseField>

## Consultar status da tarefa

```http
GET https://router.flatkey.ai/v1/videos/{task_id}
```

```bash
curl https://router.flatkey.ai/v1/videos/task_3f9a00000000000000000000000000e2 \
  -H "Authorization: Bearer $FLATKEY_API_KEY"
```

Enquanto a geração está em andamento, a resposta inclui o progresso atual:

```json
{
  "id": "task_3f9a00000000000000000000000000e2",
  "object": "video",
  "status": "in_progress",
  "progress": 50,
  "model": "seedance-2.0",
  "created_at": 1780306574
}
```

Quando a tarefa é concluída, a resposta inclui a URL do vídeo e o uso de tokens:

```json
{
  "id": "task_3f9a00000000000000000000000000e2",
  "object": "video",
  "status": "completed",
  "progress": 100,
  "model": "seedance-2.0",
  "usage": {
    "completion_tokens": 120,
    "total_tokens": 120
  },
  "metadata": {
    "url": "https://router.flatkey.ai/v1/videos/task_3f9a00000000000000000000000000e2/content"
  },
  "created_at": 1780306574,
  "completed_at": 1780306750
}
```

Tarefas com falha retornam os detalhes do erro junto com a resposta da tarefa:

```json
{
  "id": "task_3f9a00000000000000000000000000e2",
  "object": "video",
  "status": "failed",
  "error": {
    "message": "The video generation task failed.",
    "code": "video_generation_failed"
  }
}
```

Qualquer saldo pré-consumido é reembolsado automaticamente.

### Valores de status

| Status | Significado |
|---|---|
| `queued` | A tarefa está aguardando para iniciar. |
| `in_progress` | O vídeo está sendo gerado. `progress` varia de 0 a 100. |
| `completed` | O vídeo está disponível em `metadata.url` e o uso de tokens está disponível em `usage`. |
| `failed` | A geração falhou. Os detalhes estão disponíveis em `error.message` e qualquer saldo pré-consumido é reembolsado. |

## Baixar o vídeo

```http
GET https://router.flatkey.ai/v1/videos/{task_id}/content
```

```bash
curl -L "https://router.flatkey.ai/v1/videos/task_3f9a00000000000000000000000000e2/content" \
  -o output.mp4
```

O endpoint de conteúdo transmite dados `video/mp4`. Não requer um token Bearer e pode ser usado diretamente como fonte de um elemento `<video>`.

<Warning>
  O endpoint de conteúdo funciona apenas após a conclusão da tarefa e tem limite de taxa por IP do cliente. Trate a URL como informação sensível, pois qualquer pessoa que a possua pode baixar o vídeo.
</Warning>

## Erros

Erros em tempo de requisição usam o envelope de erro padrão do Flatkey:

```json
{
  "error": {
    "message": "...",
    "type": "...",
    "code": "..."
  }
}
```

| Cenário | Comportamento |
|---|---|
| `content` vazio | A requisição é rejeitada. Inclua texto não vazio, uma imagem ou um vídeo. |
| Modelo indisponível | O `model` solicitado não está habilitado para a rota. |
| Saldo insuficiente | A tarefa não é criada. |
| Falha temporária no serviço | Tente novamente mais tarde usando sua política de backoff habitual. |

## Exemplo completo

Este exemplo cria uma tarefa, consulta o status a cada cinco segundos e baixa o vídeo concluído. Requer [`jq`](https://jqlang.github.io/jq/).

```bash
#!/usr/bin/env bash
set -euo pipefail

BASE="https://router.flatkey.ai"
: "${FLATKEY_API_KEY:?Set FLATKEY_API_KEY before running this script}"

RESPONSE=$(curl -sS "$BASE/v1/videos" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      { "type": "text", "text": "An astronaut walking on the moon, cinematic lighting" }
    ],
    "resolution": "1080p",
    "ratio": "16:9",
    "duration": 5
  }')

TASK_ID=$(echo "$RESPONSE" | jq -r '.id')
echo "task: $TASK_ID"

while true; do
  RESULT=$(curl -sS "$BASE/v1/videos/$TASK_ID" \
    -H "Authorization: Bearer $FLATKEY_API_KEY")
  STATUS=$(echo "$RESULT" | jq -r '.status')
  echo "status: $STATUS"

  [ "$STATUS" = "completed" ] && break
  if [ "$STATUS" = "failed" ]; then
    echo "failed: $(echo "$RESULT" | jq -r '.error.message')" >&2
    exit 1
  fi
  sleep 5
done

VIDEO_URL=$(echo "$RESULT" | jq -r '.metadata.url')
curl -L "$VIDEO_URL" -o output.mp4
echo "saved -> output.mp4"
```

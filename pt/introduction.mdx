Flatkey é um gateway de API de IA que permite acessar 300+ modelos oficiais da OpenAI, Anthropic, Google, DeepSeek, Qwen, GLM e mais, além de 1000+ ferramentas — tudo por meio de uma única chave de API compatível com OpenAI. É um substituto direto para qualquer cliente compatível com OpenAI: altere uma linha de código (`base_url`) e suas requisições serão roteadas pelo Flatkey com até 50% de desconto em relação aos preços oficiais.

## Como funciona

O Flatkey fica entre sua aplicação e os provedores de IA. Quando você envia uma requisição:

1. Seu cliente chama `https://router.flatkey.ai/v1` com sua chave de API do Flatkey.
2. O Flatkey autentica a requisição e deduz o custo do seu saldo pré-pago.
3. A requisição é encaminhada para a API oficial do provedor (OpenAI, Anthropic, etc.).
4. A resposta é retornada diretamente ao seu cliente — sem transformação do conteúdo.

Seus prompts e respostas nunca são armazenados. O Flatkey registra apenas metadados (modelo, contagem de tokens, timestamps) para fins de cobrança e análise.

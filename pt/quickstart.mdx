O Flatkey oferece uma chave e quatro formas de usá-la. Todas as quatro compartilham a mesma conta, o mesmo saldo e o mesmo catálogo de modelos — então a única pergunta é qual delas se encaixa na sua forma de trabalhar.

<Frame>
  ![As quatro formas de usar o Flatkey, mostradas no Flatkey Console](/images/quickstart/console-choose-how.png)
</Frame>

<Tip>
  Você não precisa escolher de uma vez por todas. Comece com a opção mais próxima do que você está fazendo hoje e adicione as outras depois, usando a mesma chave.
</Tip>

## Antes de começar

Crie uma chave em [console.flatkey.ai/keys](https://console.flatkey.ai/keys). As chaves do Flatkey começam com `sk-`. Todas as opções abaixo usam essa mesma chave, então mantenha-a em uma variável de ambiente e fora do controle de versão.

Cada painel no Console também permite escolher uma chave existente em vez de criar uma nova, inserindo-a diretamente no trecho de código exibido.

## API para desenvolvedores

Chame qualquer modelo via HTTP simples com uma requisição compatível com a OpenAI. Sem SDK, sem dependências — se você tem um cliente HTTP, já está pronto.

<Frame>
  ![O painel API para desenvolvedores, com uma requisição pronta para executar](/images/quickstart/modal-api.png)
</Frame>

O Console monta a requisição para você: escolha uma chave, escolha um modelo e copie o trecho em **cURL**, **Node.js** ou **Python**.

```bash
curl https://router.flatkey.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FLATKEY_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Say hello in one sentence."}]}'
```

## SDKs para desenvolvedores

Continue usando o SDK da OpenAI que você já utiliza e aponte-o para o Flatkey. Seu código de requisição não muda — apenas a URL base.

<Frame>
  ![O painel SDKs para desenvolvedores, com a configuração do SDK](/images/quickstart/modal-sdk.png)
</Frame>

Mesma ideia de antes: escolha uma chave e um modelo, depois copie a configuração para sua linguagem.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FLATKEY_API_KEY"],
    base_url="https://router.flatkey.ai/v1",
)
```

## Flatkey CLI

Gere imagens e vídeos a partir do seu terminal, ou deixe um assistente de IA operar a CLI para você.

<Frame>
  ![O painel Flatkey CLI, mostrando instalação, login e primeiro prompt](/images/quickstart/modal-cli.png)
</Frame>

<Steps>
  <Step title="Instalar">
    ```bash
    npm i -g @flatkey-ai/cli
    ```
  </Step>
  <Step title="Fazer login">
    ```bash
    flatkey login
    ```
  </Step>
  <Step title="Comece a criar">
    Peça ao seu assistente de IA o que você deseja e deixe que ele execute a CLI:

    ```text
    Use Flatkey CLI to generate a "beautiful sunrise" picture.
    ```
  </Step>
</Steps>

<Card title="Flatkey CLI com agente de IA" icon="terminal" href="/pt/guides/flatkey-cli">
  Comandos, saída em JSON para agentes e recuperação de erros.
</Card>

## Codex & Claude Code

Conecte seu agente de codificação uma vez e depois use o Flatkey nos projetos que você já tem abertos.

<Frame>
  ![O painel Codex e Claude Code, com o comando de instalação](/images/quickstart/modal-agents.png)
</Frame>

O Console fornece um único comando de instalação para **macOS**, **Linux** ou **Windows**. Ele instala o agente se você ainda não o tiver, pede sua chave e grava a configuração para você.

<Warning>
  O instalador é interativo. Ele pergunta se você quer usar o Claude Code ou o Codex CLI, e é necessário já ter o Node.js instalado.
</Warning>

## Verifique se funcionou

Qualquer que seja a opção escolhida, abra **Usage Logs** no [Console](https://console.flatkey.ai) depois da sua primeira requisição. Você deve vê-la listada com o modelo, contagem de tokens, latência e custo.

![Use o filtro Model Name nos Flatkey Usage Logs](/images/quickstart/flatkey-usage-logs.png)

Se nada aparecer, espere alguns segundos e pesquise novamente, depois confirme a chave de API e a URL base que a requisição realmente usou.
